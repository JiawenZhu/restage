Three steps. You do the first one.

The rest happens while you watch.

1

Say what you want it to do

Not “increase saturation 12%.” An outcome: this needs to stop looking like stock. Outcomes are what the agent can plan against.

2

It writes the plan first

Five to seven ordered edits, each with the reason it is there. You read the plan before a single pixel moves — and you can cut a step you disagree with.

3

It grades its own work

After each edit a critic asks whether the step did what it claimed. When it didn’t, the agent revises and retries — without waiting for you.

WHY IT IS NOT A FILTER

Every attempt stays on the canvas — including the ones it threw away.

History is a tree, not an undo stack. When the critic rejects a step, the discarded attempt stays visible beside the retry. That is the part you cannot fake: you can see the machine change its mind.

Branch from any node and take a different direction
Rejections train a taste model that changes how the next session opens
